# Ultimate Sports Nutrition (USN) Website

## Project Overview

Ultimate Sports Nutrition (USN) is a sports nutrition e-commerce website designed to provide customers with information about sports nutrition products and allow them to browse products, make enquiries, add products to a shopping basket, and proceed to checkout.

The website contains pages for the home page, company information, products, enquiries, contact details, shopping cart, and checkout.

## Website Pages

### 1. Home Page - `index.html`
The home page introduces the USN website and displays featured products, including:
- Whey Protein
- Pre-Workout
- Shaker

Customers can use the navigation menu to access the other pages and select **Shop Now** to view the products.

### 2. About Us - `about.html`
The About Us page explains the purpose of USN and its focus on helping athletes and fitness enthusiasts achieve their health and fitness goals.

It also provides contact information and social media details.

### 3. Products - `product.html`
The Products page displays the available sports nutrition products and groups them into categories such as:
- Proteins
- Pre-Workouts
- Aminos
- Creatine
- Additionals

Each product includes an image, product name, description, price, and an **Add to Cart** button.

### 4. Enquiry - `enquiry.html`
The Enquiry page allows customers to submit an enquiry by entering:
- Full Name
- Email Address
- Phone Number
- Enquiry message

### 5. Contact - `contact.html`
The Contact page provides the business contact details and an enquiry form. It also lists the business hours.

### 6. Shopping Cart - `basket.html`
The Shopping Cart page displays products that have been added to the basket, the product price, a total amount, and a button to proceed to checkout.

### 7. Checkout - `checkout.html`
The Checkout page collects customer and delivery information and provides payment method options:
- Credit/Debit Card
- EFT
- Cash on Delivery

The customer can then place the order.

## Navigation

The website pages are connected through navigation links. The main navigation includes:
- Home
- About Us
- Products
- Enquiry
- Contact
- Shopping Cart
- Payment/Checkout

## How to Run the Website

1. Download or copy the complete project folder.
2. Make sure all HTML files are in the correct folder.
3. Make sure the `Images` folder is located in the same project folder and contains the required images.
4. Open `index.html` in a web browser.
5. Use the navigation links to move between the pages.

## Shopping and Checkout Flow

The intended customer journey is:

**Home → Products → Add to Cart → Shopping Cart → Checkout → Place Order**

The shopping cart currently shows a product and total, while the checkout page collects customer details and a preferred payment method.
